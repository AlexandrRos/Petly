# Petly

Цифровая платформа для ухода за питомцами, объединяющая владельцев и проверенных специалистов.  
Ключевая особенность — виртуальный паспорт питомца, который автоматически передаётся исполнителю при бронировании услуги.

## Концепция

Мобильное приложение, где владельцы животных находят исполнителей для передержки, выгула, ветеринарной помощи и дрессировки. Главный элемент доверия — прозрачный цифровой профиль питомца, содержащий всю необходимую информацию для безопасного и качественного ухода.

## Основные функции

### 1. Виртуальный паспорт питомца

Полная карточка животного включает:

- имя;
- фотографию;
- породу;
- возраст;
- вес;
- пол;
- статус стерилизации;
- данные о вакцинациях;
- хронические заболевания;
- аллергии;
- особенности характера (боязнь детей, агрессия к другим животным, игривость и т. д.);
- режим кормления;
- расписание прогулок;
- принимаемые лекарства;
- контакты владельца и резервный контакт.

Паспорт заполняется один раз и автоматически предоставляется исполнителю при бронировании, исключая повторный ввод данных и снижая риск недопонимания.

### 2. Поиск передержки

Владелец публикует заявку с описанием потребности, например: «Нужна передержка для корги на 5 дней».  
Исполнитель сразу видит паспорт питомца и может оценить:

- подходит ли ему животное по характеру и особенностям;
- сможет ли он обеспечить требуемый уход (лекарства, специальное питание, частые прогулки).

### 3. Поиск исполнителей

Платформа позволяет находить специалистов по направлениям:

- выгульщики;
- передержка;
- дрессировщики;
- ветеринары.

Каждый исполнитель имеет верифицированный профиль с информацией об опыте, условиях работы и принимаемых животных.

*Petly — ответственный подход к заботе о питомцах, объединяющий технологии, прозрачность и сообщество профессионалов.*
